# ⚡ EV Digital Twin Dashboard

A premium, interactive, real-time Flutter application designed to serve as a digital twin for electric vehicles (EVs). The dashboard displays live telemetry synchronized from Firebase Firestore, renders a 3D digital twin of the vehicle with visual hazard diagnostics, and maps a live GPS-based dynamic range ring.

---

## ✨ Features

- 🏎️ **3D Digital Twin Visualizer**
  - Displays a high-quality 3D render of the vehicle.
  - Features a dynamic, animated battery pack overlay that pulses green during normal operations.
  - Triggers a high-intensity red blinking warning and fire alarm icon if telemetry detects the battery temperature exceeds `45°C` (Battery Overheating state).

- 📊 **Real-time Telemetry Analytics**
  - Displays modular cards tracking crucial EV metrics:
    - **Battery SOH** (State of Health)
    - **Charge Level** (Battery Percentage)
    - **Predicted Range** (Dynamic prediction based on remaining charge)
    - **Actual Range** (Simulated actual range considering current driving conditions)
    - **Battery Temperature** (Equipped with hot/cold warning colors)

- 🗺️ **Live GPS Range Mapping**
  - Renders an ultra-sleek, CartoDB dark-themed interactive map using `flutter_map`.
  - Integrates the device's real-time physical GPS location using the `geolocator` plugin.
  - Automatically draws a dynamic range perimeter (Range Ring) scaled perfectly to the vehicle's `predictedRange` in kilometers, helping drivers visualize their true driving boundary on the fly.

- 🔥 **Firebase Cloud Integration & Simulation**
  - Utilizes a robust real-time streams listener pointing directly to Cloud Firestore (`ev_live/current`).
  - Seamlessly falls back to a realistic local mock environment (`MockEvService`) with dynamic noise generation, battery depletion, and cooling cycles if needed for offline demonstration or testing.

- **Framework:** [Flutter SDK](https://flutter.dev/) (Dart)

- **UI Design System:** Custom HSL/Material Dark Glassmorphic Design

## 🚀 Getting Started

### 📋 Prerequisites
- Flutter SDK (latest stable release recommended)
- Android Studio / Xcode configured for emulation or physical testing
- A active Firebase Project with Firestore enabled

### ⚙️ Installation & Configuration

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/your-username/ev_dashboard.git
   cd ev_dashboard
   ```

2. **Install Dependencies:**
   ```bash
   flutter pub get
   ```

3. **Firebase Setup:**
   Make sure you have your target Firebase configurations registered:
   - For Android: Place your generated `google-services.json` inside the `android/app/` directory.
   - For iOS: Place your generated `GoogleService-Info.plist` inside `ios/Runner/`.

4. **Verify Map & GPS Permissions:**
   Ensure permissions are declared in the respective platform settings:
   - **Android (`android/app/src/main/AndroidManifest.xml`):**
     ```xml
     <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
     <uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
     ```
   - **iOS (`ios/Runner/Info.plist`):**
     ```xml
     <key>NSLocationWhenInUseUsageDescription</key>
     <string>This app requires access to your location to visualize the live range ring.</string>
     ```

5. **Run the App:**
   ```bash
   flutter run
   ```

## 📈 Firestore Telemetry Schema

To feed telemetry into the dashboard, create a collection named `ev_live` with a document named `current` containing the following fields:

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `soh` | `number` | Battery State of Health percentage (e.g. `98.5`) |
| `battery_percent` | `number` | Remaining charge percentage (e.g. `85.0`) |
| `predicted_range` | `number` | Predicted range in kilometers (e.g. `382.0`) |
| `actual_range` | `number` | Actual range estimation in kilometers (e.g. `365.0`) |
| `temperature` | `number` | Battery core temperature in °C (e.g. `38.5`) |
